# The Failure Audit

## Definition
6-step diagnostic to stop narrating failure and start diagnosing it.

## Components
1. Name it
2. Identify breakdown
3. Ignored signals
4. The story told
5. The cost
6. The reframe

## Function
Post-mortem analysis without blame.

## Application Context
Post-project reviews, crisis navigation, strategic pivots.

## What It Replaces
Blame culture, randomization, and reactive firefighting.
