# The Curiosity Quotient

## Definition
Diagnostic measuring a leader's capacity for genuine inquiry.

## Components
1. Genuine Inquiry
2. Seeing Systems
3. Curiosity Under Pressure
4. Follow-Through

## Function
Pre-work assessment and Day 90 retake.

## Application Context
Leadership self-assessment, executive onboarding.

## What It Replaces
Certainty disguised as confidence.
