# The Toxicity Response Ladder

## Definition
5-step model to distinguish misalignment from toxicity.

## Components
1. Name behavior
2. Test for misalignment
3. Make expectations explicit
4. Inspect change
5. Decide

## Function
Role-play and real-world intervention for structural friction.

## Application Context
Leadership team interventions, conflict resolution, performance management.

## What It Replaces
"HR drama" and personalizing systemic failure.
